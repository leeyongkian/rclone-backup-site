rclone-backup

rclone-backup is a personal, single-user tool. It uploads an encrypted nightly backup from the owner's own server to the owner's own Google Drive using rclone.

It is not a public service. It has no sign-up, no other users, and no data collected from visitors to this page.

Google access

The app requests only the drive.file scope, which lets it create and manage the specific files it uploads. It cannot see or change any other files in the owner's Drive.
