Privacy Policy

Last updated: November 2026

rclone-backup is a personal tool used by one person (its owner) to back up their own files to their own Google Drive account. This policy explains how the app handles Google user data.

What the app accesses

The app requests a single Google OAuth scope: https://www.googleapis.com/auth/drive.file. This lets it create and manage only the files it uploads itself. It cannot read, list or modify any other files in the Drive account.

How data is used

The app uploads encrypted backup files from the owner's server to the owner's Google Drive. Google user data is used for this purpose only.

Storage and sharing

The OAuth access and refresh tokens are stored only in the rclone configuration file on the owner's own server. No data is sent to, stored by, or shared with any third party, and no data is collected from visitors to this site.

Retention and deletion

Backups remain in the owner's Drive until the owner deletes them. Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions, and the local rclone configuration can be deleted to remove the stored tokens.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
